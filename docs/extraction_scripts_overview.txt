Retail Financial Risk Scorecard

Data extraction and exploration scripts

Portfolio Project 2 | SEC EDGAR data pipeline | Stages 2 and 3: gather

1. Project at a glance

Data source: SEC EDGAR, XBRL "companyfacts" API (free, public, one JSON
file per company).

Sample: 20 US-listed retailers: 6 healthy, 6 under pressure, 8 that
failed (bankrupt or delisted). Every company is identified by its CIK
number, never by ticker.

Problem statement

US retailers operate on thin margins with heavy inventory and lease
commitments, making them vulnerable when consumer demand weakens. Using
quarterly SEC EDGAR filings from 2019 to the present, this project
examines 20 US-listed retailers, including healthy leaders, struggling
companies, and retailers that went bankrupt, to identify financial
warning signs that appear before distress events. Signals tracked are
gross margin trend, debt-to-equity, inventory growth relative to sales
growth, current ratio, free cash flow and net income. A composite health
score ranks the companies, and the project tests whether this score
would have flagged the bankrupt retailers as weak in the quarters before
they failed.

Hypotheses

-   H1: Retailers that later went bankrupt showed falling gross margin
    and rising leverage for several quarters beforehand.

-   H2: Inventory growing faster than sales appears before financial
    distress.

-   H3: A simple composite score ranks the failed retailers lower than
    healthy ones before they failed.

-   H4: Retailers that later failed filed their quarterly reports
    progressively later than normal in the quarters before failure.

  first time)

  from google.colab import drive

  drive.mount('/content/drive')

  # %% [Cell 2] Settings and folders

  import json, time

  import pandas as pd

  import requests

  from pathlib import Path

  BASE = Path("/content/drive/MyDrive/retail_risk_project")

  RAW = BASE / "raw"

  RAW.mkdir(parents=True, exist_ok=True)

  HEADERS = {"User-Agent": "Your Name your.email@example.com"} # use
  your real name + email

  companies = pd.read_csv(BASE / "companies.csv")

  print(len(companies), "companies loaded")

  # %% [Cell 3] Download one raw JSON file per company (safe to rerun:
  skips saved files)

  results = []

  for _, row in companies.iterrows():

  cik = int(row["cik"])

  out = RAW / f"{cik:010d}.json"

  if out.exists():

  results.append((row["ticker"], "already saved"))

  continue

  url = f"https://data.sec.gov/api/xbrl/companyfacts/CIK{cik:010d}.json"

  try:

  r = requests.get(url, headers=HEADERS, timeout=60)

  except requests.RequestException as e:

  results.append((row["ticker"], f"ERROR: {e}"))

  continue

  if r.status_code == 200:

  out.write_text(r.text)

  results.append((row["ticker"], f"saved ({len(r.text)/1e6:.1f} MB)"))

  else:

  results.append((row["ticker"], f"FAILED, status {r.status_code}"))

  time.sleep(0.2)

  for ticker, status in results:

  print(f"{ticker:12} {status}")

  # %% [Cell 4] Check: does each file contain the company we expect?

  print(len(list(RAW.glob("*.json"))), "files in raw/\n")

  for _, row in companies.iterrows():

  f = RAW / f"{int(row['cik']):010d}.json"

  if f.exists():

  name = json.load(open(f))["entityName"]

  print(f"{row['ticker']:12} {name}")

  else:

  print(f"{row['ticker']:12} MISSING")

  import json

  import pandas as pd

  pd.set_option("display.width", 200)

  def load(path):

  return json.load(open(path))["facts"]["us-gaap"]

  def get_series(facts, tags, kind):

  """One row per period end. kind: 'quarter', 'annual' or 'instant'
  (balance sheet)."""

  frames = []

  for priority, tag in enumerate(tags):

  recs = facts.get(tag, {}).get("units", {}).get("USD", [])

  if recs:

  d = pd.DataFrame(recs)

  d["tag"], d["priority"] = tag, priority

  frames.append(d)

  df = pd.concat(frames, ignore_index=True)

  if "start" not in df:

  df["start"] = None

  df["end"] = pd.to_datetime(df["end"])

  df["filed"] = pd.to_datetime(df["filed"])

  if kind == "instant":

  df = df[df["start"].isna()]

  else:

  days = (df["end"] - pd.to_datetime(df["start"])).dt.days

  df = df[days.between(80, 100)] if kind == "quarter" else
  df[days.between(350, 380)]

  changed = (df.groupby(["end", "tag"])["val"].nunique() > 1).sum()

  print(f" periods where one tag shows different values across filings:
  {changed}")

  df = df.sort_values(["end", "priority", "filed"])

  out = df.groupby("end").head(1).copy() # best tag, earliest filing

  out["days_to_file"] = (out["filed"] - out["end"]).dt.days

  return out[["end", "val", "tag", "form", "filed", "days_to_file"]]

Script 9: Reusable helper functions (save as sec_utils.py)

File: 09_sec_utils.py

Stage: 4. Clean the data (draft)

Purpose: Functions to load a company file, build a clean series for any
metric, list periods whose values changed between filings, and derive Q4
for flow items (revenue, income, cash flow).

Run in: Saved as sec_utils.py in the project folder, then imported

Status: Drafted; tested on synthetic data only.

Code

  import json

  import pandas as pd

  def load_facts(path):

  """Open a saved companyfacts file and return the us-gaap section."""

  return json.load(open(path))["facts"]["us-gaap"]

  def _records(facts, tags):

  """Stack the records of every tag in the list, remembering each tag's
  priority."""

  frames = []

  for priority, tag in enumerate(tags):

  recs = facts.get(tag, {}).get("units", {}).get("USD", [])

  if recs:

  d = pd.DataFrame(recs)

  d["tag"] = tag

  d["priority"] = priority

  frames.append(d)

  if not frames:

  return pd.DataFrame()

  df = pd.concat(frames, ignore_index=True)

  if "start" not in df:

  df["start"] = None

  df["start"] = pd.to_datetime(df["start"])

  df["end"] = pd.to_datetime(df["end"])

  df["filed"] = pd.to_datetime(df["filed"])

  return df

  def _filter(df, kind):

  """Keep only one type of period: 'quarter', 'annual' or 'instant'
  (balance sheet)."""

  if kind == "instant":

  return df[df["start"].isna()]

  days = (df["end"] - df["start"]).dt.days

  low, high = (80, 100) if kind == "quarter" else (350, 380)

  return df[days.between(low, high)]

  def get_series(facts, tags, kind):

  """One row per period: best-priority tag first, then earliest filing
  date."""

  df = _records(facts, tags)

  if df.empty:

  return df

  df = _filter(df, kind).sort_values(["end", "priority", "filed"])

  out = df.groupby("end").head(1).copy()

  out["days_to_file"] = (out["filed"] - out["end"]).dt.days

  cols = ["start", "end", "val", "tag", "form", "filed", "days_to_file"]

  return out[cols].reset_index(drop=True)

  def changed_periods(facts, tags, kind):

  """Show every period where the SAME tag has different values in
  different filings."""

  df = _filter(_records(facts, tags), kind)

  n = df.groupby(["end", "tag"])["val"].nunique().reset_index()

  bad = n[n["val"] > 1][["end", "tag"]]

  out = df.merge(bad, on=["end", "tag"])

  return out.sort_values(["end", "filed"])[["end", "tag", "val", "form",
  "filed"]]

  def add_q4(quarters, annual):

  """Add Q4 = annual total minus the three quarters inside that year
  (flow items only)."""

  rows, already, incomplete = [], 0, 0

  for _, a in annual.iterrows():

  if (quarters["end"] == a["end"]).any():

  already += 1 # Q4 was reported directly

  continue

  inside = quarters[(quarters["end"] > a["start"]) & (quarters["end"] <
  a["end"])]

  if len(inside) != 3:

  incomplete += 1 # can't derive safely

  continue

  rows.append({

  "start": inside["end"].max() + pd.Timedelta(days=1),

  "end": a["end"],

  "val": a["val"] - inside["val"].sum(),

  "tag": a["tag"],

  "form": "10-K (derived Q4)",

  "filed": a["filed"],

  "days_to_file": a["days_to_file"],

  })

  print(f" Q4 derived: {len(rows)} | already present: {already} |
  skipped (not 3 quarters): {incomplete}")

  out = pd.concat([quarters, pd.DataFrame(rows)], ignore_index=True)

  return out.sort_values("end").reset_index(drop=True)

7. Rules decided so far

-   Key everything on CIK, never on ticker or company name.

-   Identify each period by its end date; compute its length from the
    start date (about 91 days is a quarter, about 365 days is a year).
    Never rely on the fy and fp labels.

-   When one period appears in several filings, keep the
    highest-priority tag, then the earliest filed date (the figure as
    first reported).

-   As-of rule for testing the hypotheses: only use records whose filed
    date is before the distress date, so the evidence was public at the
    time (avoids look-ahead bias).

-   Define the tag priority list separately for each company.

-   Flow items (revenue, income, cash flow) need Q4 derived as annual
    minus the first three quarters; balance-sheet items do not.
